# LidRipple 1.0.1

## Fixes

- Restores automatic recovery after full sleep on Macs that omit the session
  lock-state field. Opening and subsequent closing no longer require a menu click
  when the system provides explicit unlocked-console evidence.
- Refreshes Screen Recording permission status whenever the menu opens.
- Preserves fail-closed behavior for missing, conflicting, or locked session state.

The owner verified full close/sleep → reopen/unlock → close again on the local
signed candidate. All 314 automated tests passed; this is not universal hardware
or fast-user-switching qualification.

## Install or update

Download **lidripple-1.0.1.dmg** below, not the source-code archive. Quit LidRipple,
open the DMG, and drag LidRipple into Applications, replacing the existing copy.
Launch it and allow Screen Recording if requested. Quit/reopen if macOS asks.

Requires macOS 14 Sonoma or later and a built-in display. Universal Apple Silicon/
Intel build; lid-following effects require compatible sensor hardware. No animation
over the lock screen. Sensor-less fallback remains experimental, with no closing
animation. A brief desktop glimpse during wake remains possible.

Developer ID signed and notarized. Captured pixels are temporarily processed on
device, not saved or uploaded by the app. DMG only; Homebrew remains deferred.

The adjacent `.sha256` file can verify the download:
`shasum -a 256 -c lidripple-1.0.1.dmg.sha256`.

Report bugs through GitHub Issues and vulnerabilities privately through Security.
